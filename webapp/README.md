## About

**UniEatsAdmin** is the companion web application for the UniEats iOS app — a social food platform for university students. Built with **Next.js**, **TypeScript**, and **Tailwind CSS**, it serves as the public-facing website providing a landing page, support resources, and privacy policy for App Store compliance.

## Features

- Landing page introducing UniEats as a social food discovery platform for students
- Support page with contact information and help resources
- Privacy policy page for App Store compliance
- Clean, responsive layout using Tailwind CSS
- Server-side rendered pages via Next.js App Router

## Technology Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
