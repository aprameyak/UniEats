## About

**UniEats** is a social eating app for university students built with **React Native**, **Expo**, and **TypeScript**. Students share real-time eating statuses to find others to grab a meal with on campus, browse a location-based feed of who's eating nearby, and connect with classmates through a friend system.

## Features

- Real-time eating status feed showing "Looking to Eat" and "Eating Now" statuses from friends
- Location-based status filtering to see who's eating nearby using Expo Location
- Campus mode to limit visibility to verified students at your university
- Photo sharing for meal posts via Expo Image Picker
- Friend system with search by name or username and friend request flow
- Profile setup with university selection and profile photo upload
- Pull-to-refresh feed and session persistence with AsyncStorage

## Technology Stack

- **Mobile**: React Native, Expo, TypeScript
- **Navigation**: React Navigation v6
- **Media**: Expo Camera, Expo Image Picker, Expo Location
- **Storage**: AsyncStorage
